## 💼 Experience & Achievements

### Summer Research Intern — IIT Ropar
**Electronics / Device-Oriented Computing Research** · 2026

- Worked on **Ferroelectric Tunnel Junction (FTJ) crossbar arrays** using Cadence Virtuoso.
- Implemented parameterized array generation with **SKILL** and modeled device behavior using **Verilog-A**.
- Explored mapping of neural-network weights onto FTJ crossbar architectures for neuro-inspired computing experiments.
- Used GPU-based experiments to evaluate neural-network inference behavior under device-level constraints.

### Semiconductor Fabrication Workshop — CSIR-CEERI, Pilani
**SHILP semiconductor fabrication workshop**

Hands-on exposure to a complete semiconductor fabrication flow including:

`Wafer Cleaning → Oxidation → Photolithography → Etching / Diffusion → Gate Oxide → Contact Opening → Metallization / Lift-off → I–V / C–V Characterization`

Worked with fabricated **P–N junction** and **MOS capacitor** structures.

### Optical Communication Research

Developed an **OptiSystem-based OCDMA simulation** investigating delay-attack-resistant optical communication using optical coding.

- Evaluated multiple code-weight configurations.
- Analyzed BER, APD and matched-decoder performance.
- Simulated a **20 km single-mode fiber link at 1550 nm**.
- Achieved a simulated **Q-factor of 10.1081** for the evaluated configuration.

### Academic & Technical Work

- **Wi-Fi Indoor Positioning:** ML-based indoor localization using Wi-Fi features, ESP32, FastAPI and an offline TFLite Android deployment.
- **Semiconductor Devices:** Practical exposure to fabrication, device characterization and transistor-level simulation.
- **Communication Systems:** Optical communication modeling, coding, BER analysis and system simulation.
- **Competitive Programming:** Actively strengthening DSA and problem-solving with C++.
